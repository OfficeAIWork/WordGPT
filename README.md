## 软件简介

OfficeAI.Chat（原 WordGPT）是一款深度适配办公全场景的 AI 智能插件，覆盖内容创作、文稿处理、智能排版、多语种翻译等核心办公需求，大幅提升文档工作效率。

| 核心能力                   | 说明                                                                                                                                                 |
| :------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------- |
| **多元内容智能生成** | 接入私有知识库或联网检索，一键产出论文、简历、博文、新闻稿、产品文案、商务邮件、影视剧本、工作总结等各类文稿；同步生成思维导图、配图、数据图表及 PPT |
| **全维度文本精加工** | 全文校对、语句润色、内容提炼、篇幅扩写与精简缩写，智能筛查语病与逻辑漏洞，输出优化改写版本                                                           |
| **多语种即时翻译**   | 覆盖全球多语种互译，满足外文写作、文档翻译、跨境办公等需求                                                                                           |
| **智能排版自动化**   | 一键自动规整全文版式、统一格式样式，省去手动排版耗时                                                                                                 |

> **适配环境：** Windows 系统（推荐 Win10+）· 苹果 macOS · 国产信创系统 · Linux 系统 · Office 2012+ · WPS 最新版

### 登录与模型配置

#### 方式一：用户登录（限时免费）

![登录界面](./Images/04-login.png)

- 勾选「OfficeAI.Chat 模型服务」，输入用户名和密码点击【确定】
- 新用户点击【免费注册】注册账号后登录

#### 方式二：自定义模型 API（永久免费）

![](./Images/05-custom-api.png)

| 配置项            | 说明                                                                                        |
| :---------------- | :------------------------------------------------------------------------------------------ |
| **模型 ID** | 推荐：深度求索 DeepSeek-V4-Flash、智谱 GLM5.1、阿里 Qwen3.7-Max、OpenAI GPT-5.5（境外用户） |
| **API Key** | 进入大模型管理后台复制 API Key 并粘贴                                                       |

> [!TIP]
> 软件已预置 DeepSeek、智谱、阿里百炼等主流平台的标准地址，选择后自动填入。内网可通过 Ollama 完全离线使用，地址格式：`http://[服务器IP]:11434/v1`

## 功能说明

### 功能菜单

![](./Images/10-feature-menu.png)

### OfficeAI 智能体

![](./Images/07-officeai-agent.png)

OfficeAI 智能体是具备自主任务拆解与执行能力的办公智能助手。仅需下达自然语言目标，智能体自动规划流程、落地执行，代替枯燥繁琐的手工操作。

#### AI 操作模式

| 模式         | 说明                                   |
| :----------- | :------------------------------------- |
| **自动**     | 智能判断操作模式                       |
| **原位替换** | 生成的内容原位替换回文档选中位置       |
| **批注**     | 生成的内容以右侧批注形式插入文档       |
| **仅对话**   | 生成的内容仅在当前对话聊天窗体         |

#### 知识库引用

勾选或聊天窗输入框 `@` 个人知识库，可基于知识库文档生成内容。

![知识库引用](./Images/39-kb-reference.png)

| 功能       | 说明                                   |
| :--------- | :------------------------------------- |
| 润色改写   | 优化文字表达，让语句更流畅、专业、地道 |
| 扩写丰富   | 在原文基础上扩展内容，增加细节描述     |
| 总结摘要   | 提炼长文本核心观点，快速获取关键信息   |
| 翻译       | 多语种互译，自动识别源语言             |
| 查找替换   | 批量替换文档中的指定文字               |

#### 排版与美化

| 功能         | 说明                                                       |

### 生成提纲

选中关键词或关键短语，点击【生成提纲】，可根据需求选择精确、平衡、创新方案。

![生成提纲](./Images/14-generate-outline.gif)

### 生成文章

选中提纲或短语，点击【生成文章】，同样支持精确、平衡、创新三种方案。

![生成文章](./Images/15-generate-article.gif)

### 疏通润色

选择需要润色的段落，点击【疏通润色】，优化结果以批注形式呈现，方便与原文对比。满意后可直接复制替换回文档。

![疏通润色](./Images/16-polish-refine.gif)

### 总结摘要

对选中段落点击【总结摘要】，结果以批注形式呈现，方便与原文对比。

![总结摘要](./Images/17-summarize.gif)

### 改写（扩写 / 缩写）

- **扩写**：选中短语点击【扩写】，可在原文基础上丰富内容，重复执行可持续扩写
- **缩写**：选中段落点击【缩写】，在不改变原意的情况下精简文字

![改写](./Images/18-rewrite.png)

### 中英互译

选中文本即可进行中英文互译，自动识别源语言。

![中英互译](./Images/19-translation.gif)

### 思维导图

> [!WARNING]
> 仅支持 Word，WPS 暂不支持

- **总结型**：选中文章段落 → 点击【思维导图】→【平衡方案】，自动生成段落结构图
- **预测型**：选中关键词 → 点击【思维导图】→【创新方案】，自动生成头脑风暴思维导图

![思维导图](./Images/22-mind-map.png)

### 智能配图

选中关键字或短语，点击【智能配图】，自动生成文章配图。

![智能配图](./Images/23-smart-illustration.png)

### 自动排版

内置「自定义」「论文」「公文」三种排版样式，支持自定义设置。设置好样式后点击【自动排版】即可自动格式化全文。

|              排版入口              |                排版设置                |
| :---------------------------------: | :-------------------------------------: |
| ![自动排版](./Images/25-auto-formatting.png) | ![排版界面](./Images/26-formatting-settings.png) |

操作视频：[Bilibili 教程](https://www.bilibili.com/video/BV1Vm42157Qj/)

### 图片转文字

支持两种识别方式：

- **截屏识别**：截取屏幕指定区域进行 OCR 识别
- **选择图片识别**：选择 JPG、PNG 等格式文件进行识别

### PDF 工具

![PDF 工具](./Images/27-pdf-tools.png)

- **导入 PDF**：选择 PDF 文件，带格式转换为 Word 文档
- **导出 PDF**：将当前文档导出为 PDF 格式文件

> [!TIP]
> 点击【PDF 工具集】按钮可打开万能 PDF 工具集，内嵌各种 PDF 相关的文件转换及编辑功能。

![PDF 工具集](./Images/40-pdf-toolkit.png)

### 生成 PPT

点击【生成 PPT】，将文档摘要填入主题框，点击【生成提纲】快速生成 PPT 提纲，支持微调后自动生成带排版内容的 PPT 演讲稿。

![生成 PPT](./Images/29-generate-ppt.png)

操作视频：[Bilibili 教程](https://www.bilibili.com/video/BV1mH4y1F7K9/)

## 个人知识库

点击【个人知识库】按钮弹窗形式打开 KHub 知识库页面，可直接浏览和管理知识库内容。知识库内容需在 KHub 知识库站点中创建和维护。

### 1）登录知识库

使用 OfficeAI.Chat 账号登录，默认为每个用户创建知识库；使用自定义模型或企业用户可在设置界面中【知识库】页签设置知识库账户。登录后进入 KHub 知识库管理页面，左侧为知识库列表，右侧为知识库内容区。

![登录知识库](./Images/34-kb-login.png)

### 2）创建知识库

1. 登录后点击【新建知识库】按钮，弹出创建弹窗
2. 填写知识库名称与描述，完成创建

![创建知识库](./Images/35-kb-create.png)

### 3）导入文档

在左侧选中一个知识库，点击【导入文档】按钮，支持三种导入方式：

![导入文档](./Images/36-kb-import.png)

| 导入方式   | 说明                                                                          |
| :--------- | :---------------------------------------------------------------------------- |
| 上传文件   | 支持 PDF / Word(docx) / TXT / Markdown 格式，单个文件不超过 15MB（具体上限以站点配置为准） |
| 粘贴文本   | 直接粘贴文本内容，作为一篇文档导入                                            |
| 粘贴网址   | 输入网页 URL，自动抓取网页内容入库                                            |

### 4）等待文档学习

文档导入后，系统自动进行向量化学习（分块 → 向量化入库 → 生成摘要与标签），状态流转为 **学习中** → **已学习**。

- 仅**已学习**状态的文档才会被 AI 检索引用
- 若显示**学习失败**，可删除该文档后重新导入

### 5）查看文档详情

在文档列表中，点击文档行右侧的**详情（i）**图标，可打开文档详情弹窗，查看并维护学习生成的文档元数据：

![文档详情](./Images/37-kb-details.png)

- **摘要** — 学习时自动生成的文档摘要，点击编辑图标可手动修改并保存
- **标签** — 学习时自动生成的主题标签，支持添加、删除与编辑保存
- **关系图** — 以知识图谱形式展示该文档与知识库内其他内容的关联关系，辅助梳理文档脉络

![知识库关系图](./Images/38-kb-relationship-graph.png)

### 6）在对话中引用知识库

文档学习完成后，回到 WPS 或 Office 的 OfficeAI 智能体面板，勾选或用 `@` 引用知识库后提问，AI 将基于知识库内容回答，并附带参考资料。

> [!TIP]
> 点击 AI 回答中的引用来源，可在弹窗中打开原文档并定位到对应段落；PDF / Word / TXT / Markdown 文档均支持免转换在线预览，站点内还提供知识图谱等功能辅助梳理文档间关联。
